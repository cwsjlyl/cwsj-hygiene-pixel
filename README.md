# 彩雲衛生小先鋒 v2 (`cwsj-hygiene-pixel`)

專為**彩雲聖若瑟小學（Choi Wan St. Joseph's Primary School）小學四年級常識科**設計的 **720p (`1280×720`) 單畫面像素風 RPG 教育網頁遊戲**。

## 🌟 v2 重大升級亮點

1. **EPX 邊緣平滑高清像素畫質 ＋ 六大房間擴充家居與捲動社區地圖**：
   - 內建 `epx2x`（Eric's Pixel Expansion）無損像素平滑演算法與雙色抖動木紋／磁磚光影渲染。
   - **擴充大屋（`2176×1408` 捲動鏡頭）**：細分為**浴室、小明睡房、溫馨客廳、廚房與飯廳、玄關走廊、陽光露台**六大區域。
   - **香港街道與公園（`2432×1408` 捲動鏡頭）**：新增冰室、藥房、漢堡快餐店、後巷垃圾黑點、動態冷氣滴水粒子及飄落樹葉特效。
2. **8 款全像素化 Phaser 3 街機小遊戲（`MinigameScene.ts`）**：
   - 全面採用專屬 `minigame-sprites.png` 32 款像素圖元（零文字 Emoji 充數），支援連擊倍率、限時能量條、像素粒子爆破與金／銀／銅牌評級！
3. **多聲道晶片背景音樂（BGM）＋ 強化角色動畫**：
   - Web Audio 多聲道合成三首主題曲（溫馨家居、活力街道、刺激小遊戲），並加入主角待機呼吸、跑步煙塵粒子、任務完成歡呼跳躍及 NPC 自主巡邏走動動畫。
